# 🐋 OrcaSlicer

OrcaSlicer is a **community slicer** with built-in **calibration** for flow and pressure advance. **Process presets** keep tuned values reusable across models.

## ✨ Key Features

- 🧪 **Calibration tests** for flow and pressure
- 🎚️ **Process presets**
- 🖌️ **Support painting**
- 🌡️ **Temperature towers**
- 🧊 **Preview with flow view**
- 🔌 **Third-party printer profiles**
- 📊 **Test result log**
- 🗂️ **Preset libraries**

## 🚀 Why Choose OrcaSlicer?

Calibration lives in the slicer instead of a separate guide. Flow and pressure tests produce values that feed directly into presets, so tuning is repeatable.

Preset libraries keep a tuned machine configuration available for every model.

## 🎮 Why Use It?

- **Calibrate flow** with a test
- **Tune pressure advance**
- **Save presets** per machine
- **Paint supports**
- **Review flow** in preview

## 🧩 Quick Start

1. Install and select a printer profile.
2. Run the flow calibration.
3. Run the pressure advance test.
4. Save the tuned process preset.
5. Slice with the preset.
